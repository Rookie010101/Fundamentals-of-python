# ⭐ My First Python Program

This is my very first Python program where I explored the use of \*\*new line (`\\n`)\*\* to create a simple pattern of asterisks (`\*`).  
It demonstrates how line breaks can be used to structure output neatly.
---
## 📜 Program Description
The program prints a pattern of asterisks using the `print()` function and newline characters.  
This helps in understanding how text formatting works in Python.
---
## 🖥️ Code Example
```python
# Program: Pattern of Asterisks
# Purpose: Showcase the use of newline characters
print("\*\\n\*\*\\n\*\*\*\\n\*\*\*\*\\n\*\*\*\*\*")
```
