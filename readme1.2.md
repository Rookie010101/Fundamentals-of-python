# (LW1.2)

## 📌 Overview
This repository contains **multiple beginner-level Python programs** written as part of **Fundamentals of Python – Lab Work**.  
The programs demonstrate core Python concepts such as:
- Output formatting
- User input
- Arithmetic operations
- Data types
- Logical operators
- Assignment operators

---

## 🧾 Program Details

### 🔹 Program 1: Output Formatting
- Demonstrates the use of `sep` and `end` parameters in `print()`.

### 🔹 Program 2: User Input & String Formatting
- Takes name, age, and hobby as input.
- Displays a formatted greeting message.

### 🔹 Program 3: Arithmetic Operations
- Performs addition, subtraction, multiplication, division, floor division, modulus, and exponentiation.

### 🔹 Program 4: Data Types
- Displays different Python data types using `type()`.

### 🔹 Program 5: Height & Weight Input
- Takes height and weight as floating-point values and displays them.

### 🔹 Program 6: Logical Operators
- Demonstrates `and`, `or`, and `not` operators.

### 🔹 Program 7: Assignment Operators
- Demonstrates `+=`, `-=`, `*=`, `/=` operators.
